# Моды и патчи

Файлы игры никогда не меняются: моды накладываются при каждом запуске, патчи применяются к образу в
памяти.

## Моды из файлов

Каждый мод — своя папка в `mods\` рядом с лаунчером (другую папку можно выбрать на вкладке
«Моды и патчи»). Принимаются варианты:

- `<мод>\dvdroot_ps4\…`, `<мод>\app0\dvdroot_ps4\…`, `<мод>\CUSA03173\dvdroot_ps4\…`;
- папки игры прямо в моде: `<мод>\chr\…`, `<мод>\parts\…` и т. д.;
- одна лишняя обёртка вокруг любого из них (архив распакован в папку со своим именем).

Регистр имён не важен (моды, сделанные в Windows, часто пишут имена по-другому). Папка
`CUSA03173-mods` рядом с игрой (соглашение shadPS4) тоже подхватывается.

**Порядок и выключение** — в лаунчере, сохраняются в `mods.json`:

```json
{"order": ["Первый", "Второй"], "disabled": ["Первый"]}
```

Ниже в списке — загружается позже и перекрывает. Новые папки включаются сами и добавляются в конец
по алфавиту.

**Как это устроено** (`launcher/src/prep/mods.cpp`): во временной папке `out\mod-game-…` строится
копия структуры игры из ссылок — символических, если Windows разрешает (режим разработчика), иначе
junction для папок и жёстких ссылок для файлов (копий, если игра на другом диске). Каталоги, где
лежат файлы модов, «раскрываются» на один уровень, файлы модов ставятся вместо файлов игры. Игра
запускается из этой папки, после выхода папка удаляется без захода внутрь ссылок.

Не поддерживаются: замена `eboot.bin`, `sce_module`, `sce_sys`, DLL-инжекторы и скриптовые плагины,
символические ссылки внутри мода.

## Патчи игры

`patches\Bloodborne.xml` — патчи сообщества для 1.09 в формате shadPS4/GoldHEN: режимы FPS
(60/90/без ограничения), разрешение сцены, эффекты, читы, детализация. Лаунчер включает нужные по
`wbp.ini` и собирает их в `out\patches.bin`.

**Сторонние патчи:** XML-файлы в папке `patches\` (или другой, выбранной в лаунчере). Берутся
`Metadata` для `AppVer="01.09"` и `eboot.bin`; файлы с `ID` других игр пропускаются. Включение по
умолчанию — из `isEnabled` файла, выбор в лаунчере хранится в `patches.json`:

```json
{"enabled": ["файл.xml/Имя патча"], "disabled": ["файл.xml/Другой патч"]}
```

- Поддерживаются строки `bytes`, `bytes16/32/64`, `float32/64`, `utf8`, `utf16`.
- Патч с поиском по шаблону (`mask`) или адресом вне eboot пропускается целиком, с сообщением в журнале.
- Сторонние патчи применяются после встроенных: при пересечении побеждает сторонний.
- Указатели в таблицах (как в `60 FPS++` и `90 FPS++`) загрузчик переносит на реальный адрес образа.

Из командной строки:

```bat
set BB_GAME_DIR=F:\games\CUSA03173
set BB_MODS_DIR=F:\games\mods
set BB_PATCHES_DIR=F:\games\patches
Bloodborne.exe --run
```

`BB_MODS_ENABLED=0` — без модов, `BB_MOD_TRACE=1` — какие файлы модов игра реально открыла.
