# Лаунчер (`launcher/`)

`Bloodborne.exe` — одна статически собранная программа на C++20 (MSYS2 CLANG64, без DLL кроме
системных). Это и окно лаунчера, и подготовка игры перед каждым запуском.

## Роли

| Запуск | Что делает | Код |
|---|---|---|
| `Bloodborne.exe` | окно лаунчера | `src/main.cpp`, `src/ui/` |
| `Bloodborne.exe --run [--after PID]` | подготовка игры и запуск `bin\bb-probe.exe`; настройки берёт из переменных `BB_*` | `src/runner.cpp`, `src/prep/` |
| `Bloodborne.exe --play` | игра с сохранёнными настройками без окна; вывод в консоль и `last_run.log` | `src/runner.cpp` |
| `Bloodborne.exe --install-update ПАПКА PID` | запускается скачанным обновлением: ждёт закрытия старого лаунчера, копирует себя поверх (кроме сохранений, настроек и модов) | `src/actions.cpp` |

## Подготовка игры (`--run`)

1. **Иконки клавиш** (`prep/key_icons.cpp`): из `menu\common.tpf.dcx` достаются иконки подсказок
   (`KG_*` и атлас интерфейса), перерисовываются под бинды через Direct2D, сжимаются в BC7 (режим 6)
   с раскладкой блоков PS4 и упаковываются обратно (libdeflate, уровень 12 — иначе архив выходит
   больше оригинала, и игра его отвергает). Результат кэшируется по биндам в `out\key_icons\`.
2. **Моды** (`prep/mods.cpp`): во временной папке строится «оверлей» игры из ссылок; файлы модов
   подменяют файлы игры. См. [MODS.md](MODS.md).
3. **Образ игры** (`prep/image.cpp`): `out\boot-linked.bin`, см. [LOADER.md](LOADER.md). Строится
   только при изменении `eboot.bin`, `libc.prx`, `libSceFios2.prx`.
4. **Профиль AppContent**: `out\content.bin` из `param.sfo`.
5. **Патчи** (`prep/patches.cpp`): режим FPS, эффекты, читы, детализация, разрешение сцены и
   сторонние патчи → `out\patches.bin`. Для версий кроме 1.09 патчи не применяются (30 FPS).
6. **Разрешение:** для вывода не 1080p считается разрешение сцены по пресету и включается патч, либо
   «на лету» (`live_resolution`, `auto` спрашивает `bb-gpu-capabilities.exe`).
7. **Онлайн:** `user\host_overrides.json` — куда игра отправит запросы к серверам PS4.
8. Запуск `bb-probe.exe`, после выхода — строка с кодом выхода и расшифровкой.

Результат побайтно совпадает с тем, что делали прежние Python-скрипты.

## Окно

- **GLFW** даёт окно и ввод, **Direct3D 11** рисует фон (пиксельный шейдер: Кровавая луна, дым,
  туман, зерно; `src/ui/gfx.cpp`), **Direct2D/DirectWrite** рисуют интерфейс на том же буфере.
  DirectWrite сам подбирает шрифты для кириллицы, арабского и CJK.
- **Свой immediate-mode интерфейс** (`src/ui/ui.cpp`): строки опций в стиле меню игры
  («‹ значение ›», колесо и правый клик листают, клик по значению открывает список), слоты биндов,
  поля ввода, ползунок-шкала, кнопки. Наведённая строка передаёт описание в правую панель.
- **Страницы** (`src/ui/launcher.cpp`): Играть, Графика, Экран и FPS, Управление, Игра и эффекты,
  Читы, Онлайн-кооператив, Моды и патчи, Дополнительно, Журнал. Q/E переключают вкладки.
- Настройки сохраняются сразу (с задержкой 0,25 с, пока тянут ползунок).
- Фоновые задачи (проверка видеокарты, обновления, загрузка FSR 4, проверка сервера, Steam)
  идут в отдельных потоках, результат показывается уведомлением.

Снимок страницы без открытия окна для разработки: `BB_LAUNCHER_SHOT=файл.png BB_LAUNCHER_PAGE=graphics
BB_LAUNCHER_MOUSE=x,y Bloodborne.exe` отрисует кадр через 2,5 с, сохранит PNG и закроется.

## Остальное

| Что | Как |
|---|---|
| Языки | английский и русский прямо в коде (`T("en", "ru")`), остальные — `lang\<код>.lng`: английский текст, табуляция, перевод |
| Видеокарта | `bb-gpu-capabilities.exe --live-resolution` (имя карты в stderr) |
| Обновления | GitHub API последнего релиза; zip скачивается WinHTTP, распаковывается miniz |
| Steam | `userdata\<id>\config\shortcuts.vdf` (бинарный KeyValues): ярлык на `Play Bloodborne.exe`, копия `.bak` |
| Ярлык на рабочем столе | `IShellLink` |
| FSR 4 | 189 файлов модели v07 с GitHub FireBurn/Q2RTX в `fsr4_shaders\` |
