# Ввод: геймпад, клавиатура, мышь

Игра читает геймпад через `scePadReadState` примерно раз в кадр. Порт отвечает на этот вызов
состоянием, собранным из геймпада, клавиатуры и мыши (`src/runtime_pad.c`). События SDL
принимает поток окна (`gpu/shim/window.cpp`), рантайм только читает их состояние.

## Геймпад

Через SDL3: DualSense, DualShock 4, Xbox и другие. Тачпад передаётся координатами; на геймпадах
без тачпада Back/Select — клик по его левой половине. Геймпад работает одновременно с клавиатурой.

## Клавиатура и мышь по действиям

Привязки задаются не к кнопкам геймпада, а к действиям: `key_<действие>=привязка|привязка` в
`bbport.ini` (вкладка «Управление»). Привязка — имя клавиши SDL (`Space`, `Return`, `Left Shift`, `F`),
`Mouse1…Mouse5` (нумерация Windows: 2 — правая, 3 — колесо) или `WheelUp`/`WheelDown`, можно с
`Shift+`, `Ctrl+`, `Alt+`. Привязка с модификатором важнее той же кнопки без него (Shift+ЛКМ —
сильная атака, ЛКМ — атака). Файл перечитывается при изменении, в том числе во время игры.

| Действие | Кнопка PS4 | По умолчанию |
|---|---|---|
| Движение | левый стик | W A S D |
| Уклонение / бег, прыжок (ещё раз на бегу) | ○ | Space |
| L3 (свободная камера, управление врагом) | L3 | F |
| Атака / сильная атака | R1 / R2 | ЛКМ / Shift+ЛКМ, Мышь 5 |
| Огнестрел / трансформация | L2 / L1 | ПКМ / Shift+ПКМ, Мышь 4 |
| Захват цели | R3 | Q, колесо |
| Флакон / предмет | △ / □ | R / C |
| Крестовина | ↑ ↓ ← → | стрелки, колесо вверх/вниз |
| Взаимодействие / назад | × / ○ | E, Enter / Backspace |
| Меню / жесты / ключевые предметы | Options / тачпад | Escape / G / T |

Заняты портом: **Insert** (меню), **F9** (запись маршрута), **F10** (мышиная камера вкл/выкл),
**левый Alt** (держать — освободить курсор).

Щелчок колеса держится как нажатие 90 мс, иначе игра, читающая ввод раз в кадр, его пропустит.

## Ходьба на клавишах

Стик геймпада никогда не прыгает: при смене W на D он проходит через диагональ, а не через центр.
Игра на резкий скачок стика (в центр или на 90°) отвечает анимацией остановки или разворота.
Поэтому `keyboard_walk`:

- из двух противоположных клавиш побеждает нажатая последней (W+S — идти, а не стоять);
- пауза до 60 мс без клавиш (W отпустили чуть раньше, чем нажали D) сохраняет направление;
- направление поворачивается к клавишам со скоростью 14 рад/с (90° примерно за 110 мс), разворот
  больше чем на 135° — сразу, как на геймпаде;
- диагонали лежат на окружности стика.

## Мышиная камера (`src/runtime_mouse.c`)

Мышь не проходит через правый стик (у того своя кривая скорости и сглаживание), а поворачивает
камеру напрямую. В функции обновления камеры игры на адресе `0x183CF2E`, где углы уже посчитаны,
стоит переход на заглушку: она сохраняет регистры, вызывает `mouse_camera(cam)` и возвращается.
`mouse_camera` добавляет накопленное движение мыши к углам `[cam+140h]` (вертикаль, с ограничениями
игры) и `[cam+144h]` (горизонталь) и делает то же, что стик при ручном вводе, чтобы игра не тянула
камеру обратно. Подробности и адреса: [ADDRESSES.md](ADDRESSES.md).

- Курсор захватывается, только когда камера в мире действительно обновляется (не в меню), окно в
  фокусе и не открыто меню Insert.
- Чувствительность — `mouse_sensitivity` (лаунчер, меню Insert), применяется сразу.
- `BB_MOUSE=0` выключает хук, `BB_MOUSE_INVERT_Y=1` инвертирует вертикаль.
- Если байты по адресу хука не совпадают с 1.09, мышиная камера не включается.

## Подсказки кнопок в игре

Иконки кнопок PS4 в подсказках («× Осмотреть») перерисовываются под ваши бинды при каждом запуске
(см. [LAUNCHER.md](LAUNCHER.md)); `key_icons=0` возвращает значки геймпада.

## Скриптовый ввод (для автоматических прогонов)

`BB_PAD_FILE=файл` — нажатые кнопки списком (`cross circle l3 …`, `lx=0..255`), файл перечитывается
при изменении. `BB_PAD_RECORD=файл` записывает маршрут по F9, `BB_PAD_REPLAY=файл` воспроизводит.
