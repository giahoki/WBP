# Как устроен порт

WBP (Windows Bloodborne Port) запускает оригинальный исполняемый файл PS4-версии игры (CUSA03173, версия 1.09)
прямо на ПК. Это не эмулятор общего назначения:

- **Процессор — нативно.** Машинный код игры (x86-64, как у ПК) выполняется на процессоре без
  трансляции. Вместо системных библиотек PS4 — небольшой рантайм, написанный только под эту игру.
- **Графика — трансляцией.** Команды и шейдеры видеочипа PS4 (AMD GCN) на лету переводятся в
  Vulkan слоем, выросшим из рендерера эмулятора shadPS4.

## Процессы

```
Bloodborne.exe                  лаунчер: окно, настройки, журнал
  └─ Bloodborne.exe --run       подготовка игры (образ, патчи, моды, иконки клавиш)
       └─ bin\wbp-game.exe      сама игра: загрузчик + рантайм + графика
            └─ (Insert → «Применить и перезапустить»: снова Bloodborne.exe --run --after PID)
```

- `Play Bloodborne.exe` запускает `Bloodborne.exe --play`: игра с сохранёнными настройками без окна
  лаунчера (ярлыки, Steam).
- Весь вывод игры идёт через канал в лаунчер (вкладка «Журнал») и в `user\last_run.log`.
- Лаунчер держит запуск в Windows job object: «Остановить» завершает и игру, и её перезапуски.

## Где что лежит

| Папка | Что внутри | Документ |
|---|---|---|
| `src/` | загрузчик `probe.c` и рантайм `runtime_*.c` (C) | [LOADER.md](LOADER.md) |
| `gpu/` | графика: перевод команд PS4 в Vulkan, апскейлеры, меню Insert (C++) | [RENDER.md](RENDER.md) |
| `launcher/` | `Bloodborne.exe`: лаунчер и подготовка игры (C++) | [LAUNCHER.md](LAUNCHER.md) |
| `src/runtime_pad.c`, `src/runtime_mouse.c` | геймпад, клавиатура, мышь | [INPUT.md](INPUT.md) |
| `patches/` | патчи сообщества для 1.09 (FPS, разрешение, эффекты, читы) | [MODS.md](MODS.md) |
| `packaging/windows/` | упаковка, `Play Bloodborne.exe`, лицензии | [BUILD.md](BUILD.md) |
| `pgo/wbp.profdata` | профиль для оптимизации по профилю (PGO) | [BUILD.md](BUILD.md) |

Адреса в коде игры, которые использует порт: [ADDRESSES.md](ADDRESSES.md).

## Файлы игрока

| Файл | Кто пишет | Что |
|---|---|---|
| `wbp.ini` | лаунчер, меню Insert | графика, эффекты, читы, бинды клавиш, чувствительность мыши |
| `%APPDATA%\wbp-launcher\settings.json` | лаунчер | папки, режим FPS, онлайн, язык лаунчера, отладка |
| `mods.json`, `patches.json` | лаунчер | порядок и включение модов, выбор сторонних патчей |
| `user\` | игра | сохранения (`savedata\`), кэш шейдеров (`cache\`), `last_run.log` |
| `out\` | `--run` | подготовленный образ игры, патчи, иконки клавиш (кэш) |
