Машинный код самой игры (x86-64) выполняется **прямо на вашем процессоре** — процессорная часть
ничего не эмулирует. Транслируется только графика: команды видеочипа PS4 переводятся в Vulkan.
Распакуйте, запустите `Bloodborne.exe`, выберите папку игры, нажмите **ИГРАТЬ**.

> [!IMPORTANT]
> **Файлы игры не входят в комплект.** Нужен ваш собственный расшифрованный дамп Bloodborne
> (CUSA03173) версии **1.09** — для патчей частоты кадров, разрешения и эффектов (другие версии
> работают в 30 FPS). Проект не связан с Sony Interactive Entertainment и FromSoftware.

## 💻 Требования

| | |
|---|---|
| **Система** | Windows 10 (1903 и новее) или Windows 11, 64-бит |
| **Видеокарта** | Vulkan 1.3 со свежим драйвером; рекомендуется от 6 ГБ видеопамяти |
| **Память** | около 6 ГБ свободной (10 ГБ для вывода 1440p / 4K) |
| **DLSS** | GeForce RTX 20-й серии и новее |

## 🎮 Как играть

1. Скачайте zip из [релизов](https://github.com/giahoki/WBP/releases/latest) и распакуйте.
2. Запустите **`Bloodborne.exe`**.
3. На вкладке **«Игра и эффекты»** выберите папку игры (ту, где лежит `eboot.bin`).
4. Нажмите **ИГРАТЬ**.

> [!TIP]
> `Play Bloodborne.exe` сразу запускает игру с сохранёнными настройками — удобно для ярлыков и Steam.

## 🌐 Онлайн (бета)

- **Сообщения, пятна крови и блуждающие призраки** других охотников — через
  [The Hunter's Dream](https://thehuntersdream.com).
- **Вход, колокола и призывы** — через сервер shadNet (по умолчанию публичный сервер shadPS4).
- Вкладка **«Онлайн-кооператив»** в лаунчере с кнопкой **«Проверить подключение»**.

**Как выйти в онлайн:**

1. Зарегистрируйте аккаунт на **[shadnet.shadps4.net](https://shadnet.shadps4.net)**.
2. В лаунчере откройте **«Онлайн-кооператив»**, включите **«Играть онлайн»** и введите **имя
   аккаунта** (не email) и пароль.
3. Нажмите **ИГРАТЬ** и на титульном экране выберите онлайн. Приветствие The Hunter's Dream
   означает, что вы в сети.

У всех, с кем вы играете, должна быть версия игры 1.09 и тот же сервер кооператива. Выключайте
читы при совместной игре — они меняют игру и для остальных.

## ⌨️ Управление

| Действие | Клавиша | | Действие | Клавиша |
|---|---|---|---|---|
| Движение | `W` `A` `S` `D` | | Захват цели | `Q` / колесо мыши |
| Камера | мышь | | Взаимодействие | `E` / `Enter` |
| Уклонение / бег (удерживать) | `Space` | | Флакон крови | `R` |
| Прыжок | `Space` ещё раз на бегу | | Предмет | `C` |
| Атака | ЛКМ | | Смена предметов | стрелки / колесо |
| Сильная атака | `Shift` + ЛКМ / мышь 5 | | Меню | `Esc` |
| Огнестрел / парирование | ПКМ | | Жесты | `G` |
| Трансформация оружия | `Shift` + ПКМ / мышь 4 | | Ключевые предметы | `T` |

Всё переназначается на вкладке **«Управление»**. Заняты портом: **`Insert`** — меню настроек,
**левый `Alt`** (удерживать) — освободить курсор, **`F10`** — мышиная камера вкл/выкл.

## 🚀 Если игра тормозит

- На видеокартах не AMD Radeon ставьте **FSR 3.1** (или **DLSS** на GeForce RTX): FSR 4 там намного
  тяжелее. Лаунчер об этом предупреждает.
- На слабом железе — пресет **Performance** и лимит **60 FPS**.
- Выключите **размытие в движении** и **тени от динамических источников** на вкладке «Игра и эффекты».
- Чёрный экран после обновления → **«Дополнительно» → «Очистить кэш шейдеров»**.

> [!NOTE]
> Нашли проблему? Включите **«Статистика кадров в журнале»** на вкладке «Дополнительно», поиграйте
> пару минут и приложите `user\last_run.log` с названием видеокарты и процессора к
> [issue](https://github.com/giahoki/WBP/issues).

## 🛠️ Сборка

Установите [MSYS2](https://www.msys2.org) с пакетами CLANG64 из
[packaging/windows/README.md](packaging/windows/README.md), затем:

```bat
build.bat
```

Игра, лаунчер и пакет (`dist\bbport-windows\` + zip) собираются за один раз, с ThinLTO и профилем
из `pgo\bbport.profdata`. Как всё устроено внутри — **[docs/](docs/README.md)** (загрузчик,
графика, лаунчер, ввод, моды, сборка).

| Часть | Язык | Где |
|---|---|---|
| Загрузчик и рантайм — системные библиотеки PS4 | C | `src/` |
| Графика — видеочип PS4 в Vulkan, апскейлеры, меню в игре | C++ | `gpu/` |
| Лаунчер и подготовка игры | C++ | `launcher/` |
